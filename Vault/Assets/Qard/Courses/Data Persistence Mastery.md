Start with **ACID transactions** and **Caching**, then follow **SQL** from data modeling and query semantics to indexes, locking, replication, and sharding. **NoSQL** starts with its data models before specialized engines. **ORMs** applies SQL access and connection ownership to Entity Framework.

**Fundamentals** contains shared guarantees, caching, connection pooling, object storage, and storage protection. Object storage and erasure coding form a later storage branch; erasure coding also uses the replication objective in SQL. Within each group, rows progress from the basic model to its operating costs and failure cases.

Learning objectives follow the linked source material. Their prerequisite links identify the knowledge needed for each target; the suggested route is guidance rather than a requirement to finish every earlier group. Teach, checks, and reviews retain their existing assessment history. Source-note lifecycle status does not establish course mastery.
