C# establishes language semantics; .NET explains execution and concurrent work; ASP.NET applies them to request processing. Other currently contains WebAssembly.

- **C#:** value and reference types, classes/structs/records, methods, strings, generics, patterns, delegates, events, exceptions, iteration, and namespaces.
- **.NET:** CLR execution and compatibility, reflection, garbage collection and retention, then tasks, async/await, cancellation, synchronization, parallelism, and channels.
- **ASP.NET:** routing and middleware, dependency injection, filters, authentication, authorization, and CORS.
- **Other:** WebAssembly and its host boundary.

Start with **Value and reference types**, **Classes, structs and records**, and **Methods and parameter passing**. Continue through exceptions and tasks to async/await, then **Routing and middleware** for API work. Reflection, synchronization, CPU parallelism, and WebAssembly are branches from their listed prerequisites; completing every branch is not required before learning ASP.NET.

Rows run from foundations to more specialized work within each group. The map uses direct prerequisites rather than treating every preceding row as a requirement. Existing assessment states, due dates, and evidence remain authoritative.
