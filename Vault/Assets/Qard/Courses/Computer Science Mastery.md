**Fundamentals** supports two parallel paths: **Data Structures** and **Algorithms**. Big O, memory locality, bits, and byte order provide shared concepts; the two paths can be studied together without completing one entire group before starting the other.

- **Fundamentals** establishes complexity analysis and data representation.
- **Data Structures** progresses from arrays and linked lists to stacks, queues, hashing, search trees, heaps, and graph representations. Specialized trees, advanced heaps, and range or spatial indexes branch from those foundations.
- **Algorithms** progresses from searching and sorting to reusable problem-solving patterns, algorithm paradigms, graph algorithms, and string matching.

Interleave the paths by learning a structure alongside algorithms that use it: arrays with searching and sorting, linked lists with fast and slow pointers, heaps with Top-K, and graph representations with DFS/BFS. Greedy algorithms can start directly from the complexity foundation. Each algorithm requires only its listed concepts or structures; advanced trees and heaps do not gate unrelated algorithms. Rows progress from foundations to specialized topics within each group, and Qard's Route here follows the prerequisites for a selected objective.

The existing objective identities, learning goals, linked sources, and assessment history remain the course record. Source-note lifecycle does not establish assessed mastery. Lessons and checks update objective states, due dates, and evidence.
