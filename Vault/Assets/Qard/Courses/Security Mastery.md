Security starts with the data and authority a system must protect, then follows credentials through sign-in, sessions, and access enforcement.

- **Fundamentals:** sensitive data, hashing, encryption, signatures, secrets, authorization models, web vulnerabilities, firewalls, OWASP categories, and blockchain trust.
- **Authentication:** credential and session foundations, password storage, Basic authentication, multiple factors, TOTP, OAuth/OIDC, JWT validation, SSO, and resource-based authorization.

Start with **Sensitive data and lifecycle controls**, then build the cryptographic foundations. Begin the sign-in path with **Authentication, credentials and sessions**, followed by password-based methods or federated login. Resource-based authorization applies the separate policy model from Fundamentals; authentication and authorization retain different responsibilities. Web vulnerabilities and network defenses form a parallel path from the security fundamentals. Blockchain is a later specialization.

Each group's rows progress from foundations to applied controls. Direct prerequisites may cross groups where the concept requires them. Existing assessment states and evidence remain intact; the credential/session foundation starts unassessed.
